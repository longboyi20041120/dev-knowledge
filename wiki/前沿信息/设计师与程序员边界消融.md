# 设计师与程序员边界消融

AI 时代的一个核心趋势：设计师和程序员的职业边界正在快速模糊化。懂设计的程序员 + 懂编程的设计师将成为下一代产品团队的标准配置。

## 为什么边界在消融

1. **AI 工具降低了双方的门槛**
   - 程序员用 AI 生成 UI 代码（v0、Claude Artifacts、Bolt.new）
   - 设计师用 AI 写交互逻辑（Figma AI、Cursor + 设计稿）

2. **产品迭代速度要求全栈化**
   - 从"设计师画图 → 程序员实现"变成"一个人从想法到上线"
   - 独立开发者（Indie Hacker）模式盛行

3. **设计工具和开发工具的趋同**
   - Figma 支持代码导出和交互原型
   - VSCode/Cursor 集成设计预览
   - 两者都在向"所见即所得 + 可编程"靠拢

## 程序员需要补的设计能力

| 能力 | 具体内容 | 日常训练 |
|------|----------|----------|
| 视觉层次 | 信息优先级、留白、对比 | 每天分析一个产品的首页布局 |
| 交互逻辑 | 用户路径、状态反馈、容错 | 用 Excalidraw 画交互流程图 |
| 设计系统 | 组件化、一致性、可维护性 | 学习 Material Design / Ant Design 规范 |
| 用户共情 | 痛点识别、场景还原 | 用产品时记录"为什么这样设计" |

## 设计师需要补的编程能力

| 能力 | 具体内容 |
|------|----------|
| HTML/CSS 基础 | 理解盒模型、Flexbox、响应式 |
| 组件思维 | 理解 props、状态、可复用设计 |
| 数据流 | API 请求/响应、状态管理概念 |
| Git 基础 | 版本控制和协作流程 |

## 对个人的启示

1. **不要站队**——不要给自己贴"我是程序员我不懂设计"的标签
2. **从日常开始**——每次写前端代码时多花 5 分钟思考交互体验
3. **用 AI 加速跨界**——让 AI 帮你补短板的领域
4. **建立双重视角**——看产品时同时从"怎么实现"和"为什么这样设计"两个角度思考
