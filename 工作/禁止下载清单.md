# 禁止下载清单

> 以下软件**禁止下载、安装、使用破解版**。需要替代品时用开源或免费方案。

## 禁止

| 软件 | 用途 | 原因 |
|------|------|------|
| **Xshell** | SSH 客户端 | 破解版有安全风险（后门/盗号），公司商用 license 很严 |
| **Navicat** | 数据库 GUI | 同上。破解版常见于灰色下载站，带毒率高 |

## 替代方案

| 需求 | 替代品 | 说明 |
|------|--------|------|
| SSH 客户端 | Windows Terminal + ssh.exe | 系统自带，零安装 |
| | VS Code Remote-SSH | 开发场景首选 |
| | Tabby / MobaXterm Free | 需要多标签/保存会话时 |
| 数据库 GUI | DBeaver（免费版） | 开源，支持 MySQL/PostgreSQL/所有主流 |
| | HeidiSQL | 轻量，仅 Windows，开源 |
| | VS Code 插件（MySQL/Database Client） | 开发场景够用 |
| | DataGrip Community | JetBrains 免费社区版 |

## 原则

- **系统自带能解决的，不装第三方**（Windows Terminal + ssh 足够日常 SSH）
- **开源优先于破解**（DBeaver 功能不输 Navicat）
- **VS Code 插件优先于独立客户端**（减少安装面）
